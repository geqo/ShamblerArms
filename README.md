# Shambler Arms

Мод для RimWorld **1.6** (под 1.7 позже, см. `docs/RESEARCH.md`). Зависит от Harmony.
Шамблерная часть работает только с Anomaly.

## Что делает

1. **Предметы не выпадают** у погибших и недееспособных пешек: оружие и инвентарь
   остаются на пешке или трупе (4 переключателя в настройках, по умолчанию включены).
   То, что пешка несла в руках, падает как обычно. Снимать вещи — ванильным «Раздеть».
   Исключения, где остаётся ванильное поведение: гладиаторская дуэль (ритуалу нужно, чтобы оружие
   выпало), пешка в кровати, `destroyGearOnDrop`, пешка в контейнере или вне карты.
   Если активен **Non Uno Pinata**, эта часть мода выключается целиком (патчи не ставятся).
2. **Вооружённые шамблеры.** Шамблер, поднятый из пешки с оружием, может его оставить.
   Новое оружие не выдаётся: готовые шамблеры из событий приходят без него, как в ванили.
3. **Интеллект шамблера** — хедифф `ShamblerArms_Intellect`, виден во вкладке здоровья.
   Значение выбрасывается один раз, при поднятии: `уровень ± разброс` из настроек.

| Интеллект | Ступень | Что умеет |
|---|---|---|
| < 25 % | безмозглый | ваниль: бросает оружие |
| 25 %+ | громила | оставляет оружие ближнего боя; сознание +5 % |
| 50 %+ | стрелок | оставляет любое оружие, ищет позицию для стрельбы не дальше 12 клеток, без укрытий; навык стрельбы = прежний × интеллект; сознание +10 % |
| 75 %+ | тактик | позиция на всю дальность оружия и с укрытием; подбирает оружие получше в радиусе 8 клеток; сознание +15 % |

Пороги ступеней и прибавки к сознанию лежат в `Defs/HediffDefs/ShamblerIntellect.xml`.
Если стрелку с огнестрелом не найти позицию, он идёт в рукопашную, а не бродит.
Шамблеры игрока не берут оружие со складов и запрещённое.

## Сборка

```sh
cd Source/ShamblerArms
dotnet build -c Release          # → 1.6/Assemblies/ShamblerArms.dll
# на другой машине: -p:RimWorldManaged=/path/to/RimWorld*_Data/Managed
```

Нужен .NET SDK 8+ и доступ к NuGet (reference assemblies net472 и Lib.Harmony только для компиляции).
`0Harmony.dll` в мод не кладётся: его даёт мод Harmony (на 1.6 это 2.4.3).

## Как устроено

| Файл | Патч |
|---|---|
| `KeepGear/KeepGearPatches.cs` | `Pawn.Kill` и `Pawn_HealthTracker.MakeDowned` помечают контекст; prefix `Pawn.DropAndForbidEverything` в этом контексте не роняет вещи; `Pawn_EquipmentTracker.Notify_PawnSpawned` не роняет оружие у лежачих |
| `Shamblers/ShamblerPatches.cs` | `Pawn_MutantTracker.Turn` (выдать интеллект), `HandleEquipment` (оставить оружие), `SkillRecord.GetLevel` (навык стрельбы), `JobGiver_ShamblerFight.TryFindShootingPosition` / `TryGiveJob` |
| `Shamblers/ShamblerThinkNodes.cs` | условие по ступени + подбор оружия |
| `Defs/ThinkTreeDefs`, `Patches/ShamblerSwarm.xml` | подбор оружия для одиночных шамблеров (тег `Shambler_PreMain`) и для роя (duty `ShamblerSwarm`) |

Декомпиляция игры для сверки: `/mnt/data/repos/rimworld-decompiled`.

## Проверка в игре (dev mode)

- [ ] Убить колониста или врага с оружием — оружие и инвентарь остаются на трупе, «Раздеть» их снимает.
- [ ] Сбить пешку с ног — оружие остаётся у неё; после сохранения и загрузки тоже.
- [ ] Гладиаторская дуэль (Ideology): у проигравшего оружие падает.
- [ ] Поднять шамблера из вооружённого трупа (dev: Resurrect as shambler) при интеллекте 0 % / 30 % / 60 % / 90 % — ступень и поведение по таблице.
- [ ] Стрелок с винтовкой стреляет, а без линии огня идёт в рукопашную.
- [ ] Тактик без оружия подбирает лежащее рядом.
- [ ] Death pall / рой шамблеров — без ошибок в логе.
- [ ] Вместе с Non Uno Pinata: в логе «Non Uno Pinata detected», переключатели скрыты.
